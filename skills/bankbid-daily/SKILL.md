# 银行业招标情报日报（订阅版）

> **数据与筛选规则在服务器**：公开银行招标数据的采集、清洗、机构识别与「在办」判定
> 都在**本平台服务器**，包内只有「读关键词 → 调端点 → 渲染」。数据每天更新，你下次调用即生效。

## 这是什么

给金融 IT 厂商、自助设备商、安防/弱电/装修工程商、金融外包服务商用：
你不是再拿到一堆公告链接，而是**每天一份能直接读的日报**——
命中你关键词的公告按时间排好、机构与品类标好、地区分好，并单独列出**14 天内就要截止**的项目。

**为什么是银行**：银行采购常年、高频、分散，且预算充足。通用招标网站把银行信息淹在几万条里，
本技能**只给银行**（另有「银行+非银金融机构」档可选），噪声低。

## 订阅与凭证

- **端点**：`https://www.tokendidi.cn/api/bankbid/api/v1/bankbid-daily`
- **订阅**：本商品为**订阅制**，**订阅价 ¥9.9/月**（按月计费、随时可停）。

- **到期**：凭证到期后调用返回 401（不会再给结论）；续费换新凭证即可，无需重装。
- **免费试用**：未填凭证也可调用，**共 3 次**服务端额度；用完返回 HTTP 402 并附购买指令。
  ⚠️ 这 3 次拿到的是**完整日报**（全部命中、每条截止时间、临近截止单列都在），
  不是「试用版少给」——本技能**只有一个版本**，免费与订阅的差别**只在于能用几次**。
- **订阅权益**：¥9.9/月 = **随时查询当日情报**（服务端查库返回）。
  ⚠️ **每一次调用都会返回当天的情报**，不是"一天只放行一次"——放心把 Agent 挂成定时任务。
  （服务端另有一道**防暴力攻击**的调用闸门；正常使用碰不到。若返回 HTTP **429**，
  说明请求过于频繁，**明天 00:00 自动恢复，无需任何操作**，也不用开工单。）

  粘贴你的 API Key 即可看到**订阅状态 / 有效期至**（页面用 POST 提交，Key 不进 URL）。
- **交付范围**：只给**还活着的** —— 正在招标 / 废标 / 公示期未结束；
  已截止、已过公示期、历史归档的**不会返回**。

## 用法

```bash
# 基本：按关键词取日报（默认只看「银行本体」）
node scripts/run.mjs --keywords "柜面系统,自助设备"

# 看在办清单（还能投的）+ 含非银金融机构
node scripts/run.mjs --keywords "安防监控" --kind active --family financial --days 30

# 试跑（用内置样例关键词；⚠️ 这是**真实查询**，会占用额度）
node scripts/run.mjs --sample
```

产物：终端直接打印排版好的 Markdown 日报；加 `--json` 拿到结构化条目；
响应里的 `report_url` 是一个**可直接打开的网页版日报**（好看、可转发）。

## 挂到每日自动化任务

对 Agent 说一句就行：

> 每天 09:00 运行银行业招标情报日报，关键词「柜面系统、自助设备」，把结果发我。

要自己挂（cron / systemd），用**包内脚本的绝对路径**，凭证用环境变量传：

```bash
# crontab -e  —— 每天 09:00 跑一次，输出追加到日志
0 9 * * * cd <你解压后的技能目录> && SKILLPAY_LICENSE=<你的凭证>   /usr/bin/env node scripts/run.mjs --keywords "柜面系统,自助设备" >> ~/bankbid-daily.log 2>&1
```

- 返回 **429** = 请求过于频繁（服务端防暴力攻击闸门），**不是出错**，明天自动恢复，不用重试；
- 只想要"还能投的"：加 `--kind active`；
- 想每天换词：把 `--keywords` 换成你自己的词（逗号分隔）。

## 关键词怎么写

| 写法 | 含义 |
|---|---|
| `柜面系统` | 单个词 |
| `柜面\|核心\|信贷` | **或**（`\|` 或逗号分隔） |
| `银行 系统` | **且**（空格分隔） |
